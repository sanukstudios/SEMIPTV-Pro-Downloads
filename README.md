# SEMIPTV Pro

IPTV player for Fire TV, Android and Windows by SANUK STUDIOS. This repository only holds the installers. The source code is private.

SEMIPTV Pro does not include any channels. You need your own IPTV subscription (M3U playlist or Xtream login).

## Install on Fire TV

1. On the Fire TV, install the free app **Downloader** from the Amazon Appstore.
2. Settings → My Fire TV → About: press OK on the first item seven times until “Developer options” appears. Then Developer options → Install unknown apps → turn on Downloader.
3. Open Downloader, enter the code **3728546** and press Go.
4. Confirm the installation.

## Install on Android

Open https://semiptv-cloud.sanuksemih.workers.dev/download on the phone or tablet and tap the download button. Allow the browser to install apps when Android asks.
